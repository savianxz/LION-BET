# 🎰 Provably Fair System - Lion.bet

At **Lion.bet**, we believe in absolute transparency. Every game result is mathematically deterministic and can be verified by anyone after the round is complete.

## How It Works

Each game outcome is generated using three variables:
1.  **Server Seed**: A cryptographically secure 256-bit secret generated by our system.
2.  **Client Seed**: A unique identifier provided by the player's session.
3.  **Nonce**: A count that increments with every round played.

### The Algorithm

We use the industry-standard **HMAC-SHA256** hashing algorithm Combined with a 5% house edge.

```typescript
// 1. Generate HMAC Hash
const hash = HMAC(serverSeed, clientSeed + ":" + nonce);

// 2. Derive 52-bit Number
const hexValue = hash.substring(0, 13);
const r = parseInt(hexValue, 16);

// 3. Apply Multiplier Formula (5% House Edge)
const crashPoint = (1 - 0.05) / (1 - (r / Math.pow(2, 52)));
const result = Math.max(1.00, Math.floor(crashPoint * 100) / 100);
```

## Verification Guide

To verify a past round, follow these steps:

1.  Navigate to your **Bet History**.
2.  Find the `Round ID` for the result you wish to verify.
3.  Combine the `Server Seed` (revealed after the round), `Client Seed`, and `Nonce`.
4.  Run the verification script below in any standard browser console or Node.js environment.

### Verification Script

```javascript
async function verifyMultiplier(serverSeed, clientSeed, nonce) {
  const encoder = new TextEncoder();
  const key = await crypto.subtle.importKey(
    "raw", 
    encoder.encode(serverSeed), 
    { name: "HMAC", hash: "SHA-256" }, 
    false, 
    ["sign"]
  );
  
  const signature = await crypto.subtle.sign("HMAC", key, encoder.encode(`${clientSeed}:${nonce}`));
  const hash = Array.from(new Uint8Array(signature)).map(b => b.toString(16).padStart(2, "0")).join("");
  
  const r = parseInt(hash.substring(0, 13), 16);
  const multiplier = Math.max(1.00, Math.floor(((0.95) / (1 - (r / Math.pow(2, 52)))) * 100) / 100);
  
  return multiplier + "x";
}
```

## Why the 5% House Edge?
To keep the platform running, we include a 5.00% statistical advantage. This means that in exactly 5% of rounds, the game will "Instant Crash" at **1.00x**, regardless of potential player actions. This transparent math ensures we can offer fair play while maintaining a sustainable platform.
